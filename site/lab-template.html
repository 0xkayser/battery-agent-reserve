    BUILDER NOTES / 01
    ONE AGENT.
    EXPLICIT LIMITS.
    Start with an agent you own. Its reserve ledger and its portable application state serve different jobs.
    1. Set a policy. Protect a balance. Bound each task and the day's expense.
    2. Reserve before dispatch. Supply a trusted worst-case quote and provider allowance.
    3. Record the receipt. Reconcile paid failures too. Unknown outcomes remain held.
    4. Fence the old worker. Restore confirmed progress on the same authoritative ledger.
    The kit has no model client, distributed custody or provider authentication. Paid-agent integration requires an actual billing adapter.
